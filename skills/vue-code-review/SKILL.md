# Vue 前端审查 Skill

目标：前端需求（页面/交互/表单/展示）在 Vue 代码里找到实现证据。

规则：
1. 核对链路：路由（页面可达）→ 组件（表单/交互存在）→ API 调用（参数与后端契约一致）→ 状态管理（加载/错误态处理）。
2. 交互细节按验收标准逐条核：按钮禁用态、输入校验、提示文案、loading 状态、列表空态。
3. 前后端契约不匹配（前端传的参数后端接口没有）是高风险缺口，gap 里必须写明两侧的字段差异。
4. status/verdict 判定与证据规则同 java-code-review：not_found ≠ fail；fail 必须有证据。
5. 找不到页面（路由/组件都不存在）时，先确认需求是否纯后端需求，避免误报前端缺口。
